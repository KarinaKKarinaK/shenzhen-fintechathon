## 5. What is simulated

In the live engine the farmer, the pilot, the lender and the vendor are scripted actors with demo keys derived from public strings (demo only, anyone can derive them). Flight telemetry is synthetic. Inside the engine the Bond, JobBoard and Lease rules run in TypeScript mirrors of the deployed contracts and only IntentLog is called on chain; section 3 is the same flow run against the deployed contracts themselves. The public app runs in simulated mode and labels every hash; real mode needs the demo token. The captured run had no model key set, so every explanation in it is the labelled template text (source template); decisions never depend on the model. With a key the model rewords explanations and the ask the agent replies, checked against the facts.
