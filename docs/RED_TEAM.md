## Benign set

Ordinary requests that must pass the same gate. A gate that blocks these is useless to a farmer.

All 7 passed.

## How the layers are tested

| Layer | Input | Blocked where |
|---|---|---|
| message | A message to the agent: injection, impersonation, a payee in the text, a fake lender notice, pressure | `framing.ts` rules plus the classifier in `ml/gate.ts`, before the agent reads it |
| policy | A signed intent that breaks a rule: unknown payee, over cap, replay, wrong signer, a payee from message text | `policy.ts`, on the signed intent, before any mirror or contract moves money |
| contract | A proof or a call that must revert: foreign evidence, stranger signature, a hunter on a live job, a second use of a proof | the mirrors in `contracts.ts`, with the same case in `contracts/test` |

The cases live in `web/src/engine/attacks.ts` (52 entries). `pnpm test` fails if any attack passes or any benign message is held. The Evidence page in the app runs the same set at request time.
